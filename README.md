# パチスロ リール制御開発システム

パチスロ（回胴式遊技機）の停止制御（0〜4コマのスベリ計算・優先度判定）を設計・シミュレーション・検証するためのモバイル対応Webツールです。

## 構成

- `index.html` — 画面マークアップ（HUD・21コマタップボード・各種モーダル）
- `css/style.css` — カスタムスタイル
- `js/constants.js` — 図柄・初期リール配列・有効ライン・初期マスターデータ
- `js/state.js` — アプリ全体で共有する状態管理
- `js/utils.js` — 座標計算・共通ユーティリティ
- `js/engine.js` — スベリ計算・優先度判定コアエンジン
- `js/ui/` — HUD・シミュレータ操作・各種モーダルUI
- `js/main.js` — 初期化・イベントハンドラ登録
- `docs/spec.md` — 要件定義・仕様書

## 動作方法

ビルド不要の静的サイト（HTML + CSS + ES Modules JS）のため、GitHub Pages などの静的ホスティングまたはローカルHTTPサーバーでそのまま動作します。

```bash
python3 -m http.server 8000
```
