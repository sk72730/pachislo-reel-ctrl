# パチスロ リール制御開発システム 要件定義・仕様書

## 1. システム概要
本システムは、パチスロ（回胴式遊技機）の停止制御（スベリコマ数）の設計・シミュレーション・検証を行う開発支援ツールです。
リール回転アニメーションは行わず、成立フラグと各リールの停止操作（目押し位置）を入力することで、0〜4コマのスベリ計算を行い、停止図柄・入賞判定・スベリテーブルを即座に表示・検証します。

---

## 2. 前提データ定義

### 2.1 リール配列
* リール数：3リール（左リール、中リール、右リール）
* コマ数：各リール21コマ（0番〜20番）
* 各コマに配置する図柄（図柄名・図柄ID、小役A/B/Cバリエーション含む）を定義・編集可能

### 2.2 有効ライン定義
* 標準有効ライン（5ライン）
  * 中段ライン、上段ライン、下段ライン、右下がりライン、右上がりライン

### 2.3 役（フラグ）・配当・代用図柄
* 各役の名称、構成図柄パターン、払出枚数、優先揃いライン、代用図柄を定義
  * **同一図柄揃い**（例：赤7・赤7・赤7、ベル・ベル・ベル）
  * **異種図柄の組み合わせ（リーチ目役・1枚役・特殊役）**：
    * 左・中・右でそれぞれ異なる図柄を指定した役の定義に対応（例：`赤7・特殊(xx)・赤7`、`ベル・リプレイ・スイカ`、`黒BAR・ベル・ベル` など）。
    * 各リールの対象図柄には、単一図柄だけでなく「任意の図柄（ANY）」の指定も可能。
    * 払出枚数は0枚（リプレイ・純粋なリーチ目）、1枚（ボーナス重複用の1枚役）、2〜15枚など任意に設定可能。
  * **優先揃いライン設定**：
    * 役ごとに「指定なし（最小スベリ優先）」「中段ライン優先」「下段ライン優先」「上段ライン優先」「右下がり優先」「右上がり優先」を指定し、中段・下段まで滑らせる制御が可能。
  * **代用図柄（変則押し救済パターン）**：
    * 押し順条件（変則押し時のみ／中押し時のみ／逆押し時のみ／全押し順）およびフォールバック条件（本来図柄が引き込めない時のみ有効）を指定可能。
  * **ハズレ**（いずれの役も入賞していない状態）

---

## 3. フラグ管理仕様

### 3.1 単独フラグ
* 特定の1役のみが成立している状態。

### 3.2 共通フラグ（同時成立・重複役）設定
* 複数の役が同時に成立している状態を「共通フラグ」として定義・保存可能。
  * 例1：ボーナス重複1枚役（特殊1枚役 ＋ ボーナス）
  * 例2：共通役（赤7ボーナス ＋ 白7ボーナス）
  * 例3：複数小役の複合（ベル ＋ スイカ）

### 3.3 共通フラグ引き込み優先度設定
共通フラグ内の複数の役がいずれも引き込み範囲（0〜4コマ）に存在する場合、どちらを優先して引き込むかの決定規則を設定可能とする。

1. **役種別優先ルール（プリセット選択）**
   * **小役優先**：小役とボーナスが重複している場合、小役の引き込みを優先（現行機基準）。
   * **ボーナス優先**：ボーナスと小役が重複している場合、ボーナス図柄の引き込みを優先。
   * **最大払出優先**：成立役の中で最も払出枚数が多い役を優先。
2. **個別優先順位設定（カスタム）**
   * 共通フラグごとに、成立役の優先順位リストをユーザーが直接並び替えて指定可能。
3. **同優先度・同一役内の決定則**
   * 優先順位が同一の役が複数引き込める場合、後述の「最小スベリ原則（できるだけ滑らない）」に従って最短停止位置が選択される。

## 4. スベリ制御基本ロジック

本システムにおける停止位置決定は、以下の優先度階層に従って厳密に判定・決定されます。

### 4.1 制御判定の優先順位

| 優先度 | ルール名 | 内容 |
| :--- | :--- | :--- |
| **第1優先** | **スベリコマ数制限** | スベリコマ数は必ず **0コマ〜4コマ** の範囲内とし、5コマ以上は絶対に滑らない。 |
| **第2優先** | **不成立役の入賞禁止** | 成立していない役（小役・リプレイ・ボーナス・特殊役・条件外の代用図柄）を入賞ライン上に揃えさせない（未停止リールがANYの場合の不可避入賞も事前除外）。 |
| **第3優先** | **成立役の引き込み** | 0〜4コマの範囲で成立役が入賞ラインに引き込める場合、優先揃いラインおよび本来図柄→代用図柄の順で必ず引き込む。<br>※共通フラグ時はセクション3.3の優先度設定に従う。 |
| **第4優先** | **取りこぼし時制御<br>（非引き込み時ポリシー）** | 成立役が引き込めない位置を押した場合（取りこぼし確定時）、セクション4.2で設定された挙動ポリシーに従って停止候補を絞り込む。 |
| **第5優先** | **最小スベリ原則<br>（できるだけ滑らない）** | 以上の条件を満たす停止位置候補が複数残っている場合、**最もスベリコマ数が小さい（押した位置に最も近い）停止位置**を採用する。 |

---

### 4.2 取りこぼし時（非引き込み時）の挙動ポリシー設定

プレイヤーが目押しをミスし、0〜4コマ以内に成立役を引き込めない場合の挙動を設定可能とします。

1. **最短停止ポリシー（デフォルト）**
   * 不成立役が揃わない範囲で、最もスベリコマ数が小さい位置（可能な限りビタ止まり0コマ）で停止する。
2. **ガセテンパイ回避ポリシー（テンパイ蹴飛ばし制御）**
   * 第1停止または第2停止において、すでに成立役を取りこぼしている場合、**「あたかもまだ成立役が揃うかのように見せるテンパイ形（ガセテンパイ）」を回避**する。
3. **テンパイ維持ポリシー（煽り制御）**
   * ガセテンパイ回避とは逆に、取りこぼし時であっても第2停止まではテンパイ形を極力維持し、第3停止でハズレ目（こぼし目）となるように引き込む。

---

## 5. 特殊スベリ制御（カスタム条件設定）

「第4優先・第5優先」による標準制御を上書きし、特定のリーチ目演出やスベリ演出を実現するための個別条件設定です。

### 5.1 条件トリガー
* **成立フラグ**：指定の単独役または共通フラグ
* **操作対象リール**：左 / 中 / 右
* **目押し位置**：押下コマ番号（0〜20）

### 5.2 アクション
* **強制スベリコマ数指定**：指定コマ数（0〜4コマ）滑らせる。

### 5.3 フェイルセーフ（安全制約）
* 特殊制御が指定された場合でも、**「第1優先：4コマ以内」および「第2優先：不成立役の入賞禁止」は常に最優先**され、不正な入賞が発生する候補は自動的に除外される。

---

## 6. UIおよび操作フロー仕様

### 6.1 シミュレーション操作フロー
1. **成立フラグ選択**：ハズレ、単独役、共通フラグ（同時成立）を選択。
2. **取りこぼし時ポリシー選択**：最短停止 / ガセテンパイ回避 / テンパイ維持。
3. **目押し指定**：
   * 21コマタップボード上の任意のコマをタップして停止（最初に押したリールから順押し／変則押しを自動判定）。
   * 上部HUDの停止リール窓またはステータスをタップすると、そのリールだけを回転中状態に戻して押し直し可能。
4. **結果表示**：
   * 停止位置、スベリコマ数、3×3ウィンドウの出目、最終入賞役と払出枚数、および優先度別の判定ログを表示。

### 6.2 スベリテーブル（一覧表）自動生成機能
* 選択した成立役において、各リールの全21コマ（0〜20番）を目押しした場合のスベリコマ数一覧表（0〜4）を一括表示し、CSV形式でエクスポート可能。

---

## 7. 入出力仕様
* **リール配列・役・代用図柄・共通フラグ・特殊制御・停止状態**：JSON形式でのファイル保存／クリップボードコピー／インポートに対応。
* **スベリテーブルデータ**：CSV形式での出力に対応。
